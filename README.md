# CTF Workspace

Shared workspace for CTF challenges — collaboration between Kundan and Claude.

## How we interact

- **You** drop a challenge into `challenges/` (a description, file, URL, hash,
  ciphertext, binary, whatever) — commit & push, or just paste it in chat.
- **I** analyze it, write scripts/notes under `scratch/`, and put the final
  writeup + flag under `solutions/`, then push here.
- We iterate in chat; this repo is the durable record.

## Layout

```
challenges/   # incoming challenges (one folder per challenge)
solutions/    # writeups + flags
scratch/      # working scripts, intermediate artifacts
```

## Categories

Web · Crypto · Reverse Engineering · Pwn/Binary Exploitation · Forensics ·
Stego · OSINT · Misc/Programming

## Ground rules

- Authorized / educational CTF play only.
- Paste the challenge or push it under `challenges/`, tell me the category if
  you know it, and we go.
